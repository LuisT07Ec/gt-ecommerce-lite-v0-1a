Especificación del modelo de datos de las 6 hojas de cálculo integradas con el proxy backend serverless, lógica de negocio heredada y checkout WhatsApp para GT E-commerce Lite.

1. Resumen Arquitectónico de las 6 Hojas

El sistema utiliza Google Sheets como base de datos cloud de bajo coste, alta disponibilidad y fácil administración. El frontend en Astro se comunica mediante un Proxy Backend Serverless seguro (evitando exponer credenciales en el cliente) que interactúa con las hojas a través de Apps Script y almacenamiento local de contingencia.

Pestaña (Hoja) Operación Endpoints Asociados Propósito Principal
Configuracion Lectura GET /api/config Almacena variables maestras de la tienda (branding, URL, carrusel, WhatsApp, moneda).
Producto Lectura GET /api/config Catálogo de productos, categorías, imágenes, precios, variantes y cantidad mínima requerida.
Agencia Lectura GET /api/config Modalidades de entrega activas, tarifas de envío asociadas y tiempos de entrega estimados.
FormaPago Lectura GET /api/config Métodos de pago aceptados y su estado (Efectivo, Transferencia, Tarjeta de crédito).
Venta Escritura / Consulta POST /api/orders
GET /api/orders/[id]
PATCH /api/orders/[id]		 Registro maestro de órdenes con código UUID, datos del cliente, estado y respaldo JSON completo.
DetalleVenta Escritura POST /api/orders Desglose pormenorizado de los ítems de cada pedido para reportes y facturación.

6. Hojas Transaccionales: Venta y DetalleVenta Registro Maestro y Detalle

Cada pedido recibido por el checkout genera una fila en Venta identificada por un UUID único, y múltiples filas vinculadas en DetalleVenta.

Hoja Columnas (A-P) Descripción Operativa
Venta
(Cabecera de Orden)		 [A] Codigo [B] Fecha [C] Hora
[D] Nombre [E] Documento [F] Telefono
[G] Correo [H] Direccion [I] Agencia
[J] Moneda [K] Total [L] Json_Raw
[M] Costo_Agencia [N] Tiempo_Agencia
[O] Estado [P] Backup_Edicion 		El Codigo es el UUID único que rastrea la orden. Estado inicia en SOLICITADO y puede transicionar a PAGADO vía API. Json_Raw almacena el payload íntegro para garantizar reproducibilidad sin pérdida de datos. Si se re-edita el pedido vía ?o=e&id=, el estado previo se respalda en Backup_Edicion.
DetalleVenta
(Líneas de Facturación)		 [A] Id_Venta [B] Producto [C] Categoria
[D] Cantidad [E] Precio [F] Subtotal 		Id_Venta actúa como clave foránea que enlaza con el UUID de la tabla Venta. Desglosa cada variante comprada, calculando el subtotal exacto de línea (Cantidad × Precio) para auditoría de inventario.

7. Script de Inicialización Automática (Google Apps Script)

Para construir esta estructura de 6 hojas en una hoja de Google Sheets en blanco con encabezados, formatos y datos de prueba en 1 solo clic, pega el siguiente código en Extensiones > Apps Script y ejecuta la función:

function inicializarEstructuraTienda() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();

  // 1. Pestaña: Configuracion
  var sheetConf = ss.getSheetByName("Configuracion") || ss.insertSheet("Configuracion");
  sheetConf.clear();
  sheetConf.getRange(1, 1, 10, 2).setValues([
    ["Logo", "/fotos/logo-wigoo.svg"],
    ["Nombre", "WIGGER SHOP 2"],
    ["URL", "https://wigooshop.ec"],
    ["Carrusel", '["/fotos/banner-mayorista-1.svg", "/fotos/banner-ofertas-2.svg", "/fotos/banner-envios-3.svg"]'],
    ["FormaEntrega", '["PASO RETIRAR", "ENVÍO A DOMICILIO"]'],
    ["FormaPago", '["Efectivo", "Transferencia", "Tarjeta de crédito"]'],
    ["Contactabilidad", "593992576986"],
    ["Moneda", "$"],
    ["TipoFormato", "es-EC"],
    ["Decimales", 2]
  ]);
  sheetConf.getRange("A1:A10").setFontWeight("bold");

  // 2. Pestaña: Agencia
  var sheetAgencia = ss.getSheetByName("Agencia") || ss.insertSheet("Agencia");
  sheetAgencia.clear();
  sheetAgencia.appendRow(["Agencia", "Costo", "Tiempo"]);
  sheetAgencia.appendRow(["PASO RETIRAR", 0.00, "15 min"]);
  sheetAgencia.appendRow(["ENVÍO A DOMICILIO", 1.50, "35 min"]);
  sheetAgencia.getRange("A1:C1").setFontWeight("bold").setBackground("#e2e8f0");

  // 3. Pestaña: FormaPago
  var sheetPago = ss.getSheetByName("FormaPago") || ss.insertSheet("FormaPago");
  sheetPago.clear();
  sheetPago.appendRow(["ID", "Tipo", "Estado"]);
  sheetPago.appendRow([1, "Efectivo", "ACTIVO"]);
  sheetPago.appendRow([2, "Transferencia", "ACTIVO"]);
  sheetPago.appendRow([3, "Tarjeta de crédito", "ACTIVO"]);
  sheetPago.getRange("A1:C1").setFontWeight("bold").setBackground("#e2e8f0");

  // 4. Pestaña: Producto (Soporte de Variantes y Cantidad Mínima)
  var sheetProd = ss.getSheetByName("Producto") || ss.insertSheet("Producto");
  sheetProd.clear();
  sheetProd.appendRow([
    "Nombre", "Descripcion", "Variedades", "Variedades2", "Precio",
    "Categoria", "Imagen", "Minima", "Badge", "PVP_Original", "Ref"
  ]);
  sheetProd.appendRow([
    "Buzz Lightyear",
    "Figura y peluche espacial de 20cm con acabados de lujo.",
    "1 Docena - 20cm",
    "Clásico Espacial, Guardián Galáctico, Edición Glow",
    10.00,
    "DISNEY",
    '["/fotos/buzz-lightyear.svg", "/fotos/buzz-lightyear-2.svg"]',
    1,
    "Popular",
    18.00,
    "WG-BZ2025-EC"
  ]);
  sheetProd.getRange("A1:K1").setFontWeight("bold").setBackground("#e2e8f0");

  // 5. Pestaña: Venta (Maestro con UUID y Estado)
  var sheetVenta = ss.getSheetByName("Venta") || ss.insertSheet("Venta");
  sheetVenta.clear();
  sheetVenta.appendRow([
    "Codigo", "Fecha", "Hora", "Nombre", "Documento", "Telefono",
    "Correo", "Direccion", "Agencia", "Moneda", "Total", "Json_Raw",
    "Costo_Agencia", "Tiempo_Agencia", "Estado", "Backup_Edicion"
  ]);
  sheetVenta.getRange("A1:P1").setFontWeight("bold").setBackground("#e2e8f0");

  // 6. Pestaña: DetalleVenta (Líneas de Facturación)
  var sheetDetalle = ss.getSheetByName("DetalleVenta") || ss.insertSheet("DetalleVenta");
  sheetDetalle.clear();
  sheetDetalle.appendRow(["Id_Venta", "Producto", "Categoria", "Cantidad", "Precio", "Subtotal"]);
  sheetDetalle.getRange("A1:F1").setFontWeight("bold").setBackground("#e2e8f0");

  SpreadsheetApp.getUi().alert("✅ Estructura de las 6 hojas creada exitosamente.");
}
